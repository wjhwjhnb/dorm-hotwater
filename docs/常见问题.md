# 常见问题

## 安装与配置

**Q：双击 `安装配置.bat` 一闪就没了 / 提示找不到 Python**

装一个 [Python 3.9+](https://www.python.org/downloads/)，安装时**务必勾选
"Add python.exe to PATH"**。

⚠️ **不要用微软商店版的 Python** —— 那个 `python` 是个假壳子，装不了依赖。
安装脚本会自动跳过它。

**Q：提示 `pip install bleak requests` 失败**

多半是网络问题。手动执行：

```
python -m pip install bleak requests -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**Q：扫描不到水控器**

依次检查：
1. 电脑蓝牙是否打开（设置 → 蓝牙）
2. 是否在水控器几米范围内
3. **手机上是否正开着乐校通并连着这台设备** —— 蓝牙设备一次只能被一个主机连接，
   手机连着的时候电脑就连不上。把手机上的小程序退到后台或关掉蓝牙再试。

**Q：扫描到了好几台设备，我选哪个**

列表里每台都显示了**房间号**（从服务器查的），选你自己宿舍那台即可。
如果信号特别弱（低于 -90 dBm）的通常是楼上楼下的。

## 登录

**Q：为什么要登录？不能直接用吗**

水控器只认**服务器签发的令牌**，而令牌需要登录后才能拿到。这是设备侧的
防绕过设计，绕不过去。

**Q：我的密码安全吗**

- 密码**只在你本机内存里**用于构造一次登录请求，**不写盘、不打日志、不上传**
- 如果登录失败，程序也不会保存密码
- 源码是公开的，你可以自己检查 `src/lxt_login.py`

**Q：验证码好难认 / 老是提示"验证码已过期"**

验证码有效期很短（大约 1 分钟），所以要**看到图片就快点输入**。
提示"已过期"就是输慢了，重新跑一次即可。

装了 `ddddocr` 可以自动识别：`python -m pip install ddddocr`（可选，要下载 100MB 左右）。

**Q：登录成功但提示"没有拿到 tokenInfo"**

说明服务端没按预期下发 cookie。请提 issue，并附上**打码后的**响应头。

## 使用

**Q：提示「用户身份失效 (-44)」**

登录票据过期了。重新跑一次 `登录乐校通.bat`。

实测票据有效期至少 6 小时，可能接近一天。开了保活（`python src/keepalive.py --install`）
之后基本不用管。

**Q：提示「请求已过期，请核对设备时间 (-45)」**

这个错误码有两个含义：
1. `X-Ghost` 请求头算错了（本项目会自动按当前时间生成，正常不会出现）
2. 登录验证码错误或过期

如果你在改代码碰到这个，先检查 `X-Ghost` —— 它**不是随机数**，见
[协议说明](协议说明.md#-x-ghost--设备时间指纹最容易踩的坑)。

**Q：提示「该设备正被他人使用中」**

这台水控器正被**别人**用着（洗澡中）。等一会儿再试。
（我在开发时真的碰到过：晚上 21:45 收到回复 `06` + 别人的学号。）

**Q：开阀成功了但水很小 / 没水**

那是水压或设备本身的问题，不是本工具的问题。工具只负责让水控器放行。

**Q：能关阀但开阀失败**

开阀需要服务器令牌（要联网），关阀不需要。所以如果网络有问题，
就会出现"能关不能开"。

**Q：会多扣钱吗**

不会。这就是正常的用水计费，和你用小程序开一样，走你自己的账户。

## 兼容性

**Q：我们学校设备型号不一样，能用吗**

目前只在 **BT19S-T** 上完整验证过。小程序源码里还有 DSK / LRD / GM510 / ESP
等分支（不同的蓝牙服务/特征值 UUID），理论上可以适配：

| 型号 | 服务 | 特征 |
|---|---|---|
| 默认 (BT19S-T) | `FFE0` | 写 `FFE2` / 读 `FFE3` / 通知 `FFE1` |
| DSK | `6E400001` | `6E400002` / `6E400003` |
| LRD | `FE60` | `FE61` / `FE62` |
| GM510 | `A002` | `FFFE` / `8910` |
| ESP | — | `C304` / `C305` |

欢迎提 issue 附上你的设备信息（蓝牙服务 UUID + F0 命令返回）。

**Q：支持手机吗 / 支持 Mac 吗**

目前只做了 Windows + 电脑蓝牙（依赖 `bleak`，理论上 Linux/macOS 也能跑，
只是桌面快捷方式那部分是 Windows 专用的）。

## 安全边界

**Q：这个工具会不会被别人拿去控制我的设备**

不会。工具用的是**你自己的**登录票据，只能操作你账号权限内的设备。
它不知道也无法获取别人的账号。

**Q：能帮别人开阀吗**

不能，也不应该。见 `LICENSE` 里的使用须知。

**Q：为什么不做"自动过验证码"**

那属于绕过计算机信息系统的安全保护措施，法律和平台风险都很高，
而且**短信验证码本来就是发到用户自己手机上的，程序拿不到**——
想让短信也自动化，只能靠手机装转发 App 或接打码平台，两条路都不现实。

本项目选择"复用你已经登录好的会话 / 登录一次后保活"，不碰这两道验证码。
