# 宿舍热水一键开关（乐校通）

> 双击桌面图标 → **约 4 秒出水**。不启动微信、不打开小程序、没有开屏广告。
> 也可以在命令行一键关阀。

---

## 它解决什么问题

学校的乐校通小程序，开一次热水要：看开屏广告 → 进小程序 → 找设备 → 滑动开阀。
洗完还要再走一遍关阀。

这个工具把它变成**桌面上的两个图标**。

## 快速开始

### 1. 前置条件

| 条件 | 说明 |
|---|---|
| Windows 电脑 | 需要**蓝牙**（笔记本自带即可） |
| Python 3.9+ | [下载](https://www.python.org/downloads/)，安装时**勾选 "Add python.exe to PATH"** |
| 微信 PC 版 | 用来登录（见下方说明） |
| 蓝牙水控器 | 宿舍里的那个，型号 BT19S-T 等 |

> ⚠️ **不要**用微软商店版 Python（那个 `python` 是假的，装了也跑不了）。

### 2. 一键配置

下载本仓库（或用 git clone），然后**双击 `安装配置.bat`**。

它会：

```
[0] 环境自检      检查 Python / 依赖 / 蓝牙
[1] 获取登录票据   读取你在微信里已经登录好的会话（不碰密码、不碰验证码）
[2] 选择水控器     自动扫描附近的设备，并查出每台是哪个房间，你按数字选
[3] 确认信息
[4] 试跑 + 生成桌面「开热水 / 关热水」图标
```

第 2 步会长这样：

```
  [1] 某区某栋某层某室      信号  -70 dBm   BT19S-T    AA:BB:CC:DD:EE:FF
  [2] 某区某栋某层某室      信号  -91 dBm   未命名      48:87:2D:62:FE:86

输入序号（0 = 重新扫描）: 1
```

**你只需要按个数字。** 不用手工选楼栋、楼层、房间号——工具通过蓝牙信号
+ 服务器查询自动识别，并且**换任何学校都能用**。

### 3. 日常使用

| 想做什么 | 怎么做 |
|---|---|
| 开热水 | 双击桌面 **「开热水」** |
| 关热水 | 双击桌面 **「关热水」** |
| 看设备信息 | `python src/lxt_ctl.py status` |
| 看协议细节 | `python src/lxt_ctl.py open -v` |

## 关于「登录」这件事（重要）

**本工具不接收你的密码，也不需要验证码。**

乐校通的登录流程是：

```js
POST user/login/userLoginV2
     { studentMobile, loginPassword, code }   ← code 是手机短信验证码
```

短信验证码是发到**你自己手机上**的，程序无法获取。所以任何声称"全自动登录"的
做法，要么得在手机上装一个转发短信的 App，要么得接打码平台（要付费、要 API key）。

**本工具的做法是：复用你已经登录好的微信会话。**

```
你：在微信里正常打开并登录一次「乐校通」
工具：把这次登录产生的会话读出来，用于操作水控器
```

**当票据过期时**（约 30 分钟无活动后会失效），工具会提示你：

> 请在微信里重新打开一次乐校通，然后重跑「一键配置」。

> 💡 如果你希望工具用起来更省事，可以让它常驻后台定时保活
> （每隔几分钟自动访问一次，使会话不过期）。这部分见 `docs/开源计划.md`。

## 工作原理

水控器是**蓝牙设备**，开关阀是通过 BLE 直接发给它。但设备只认**服务器签发的令牌**，
所以完整链路是「蓝牙 + 服务器」配合：

```
开阀（实测约 4 秒）
 ┌ BLE ──────────────────────────────────────────┐
 │ ① cmd F0   取设备信息 → SN / MAC               │
 │ ② cmd 08   取随机数                            │
 │ ③ cmd 02   授权(type=01) → 设备给出"挑战"        │
 └────────────────────────────────────────────────┘
 ┌ HTTP ──────────────────────────────────────────┐
 │ ④ getMachineByMac  按 MAC 查 deviceVer          │
 │ ⑤ bath/handleData  把挑战送服务器               │
 │      → 服务器签发 systemData(16B) + systemTime   │
 └────────────────────────────────────────────────┘
 ┌ BLE ──────────────────────────────────────────┐
 │ ⑥ cmd 06   把令牌发回设备(type=01) → 开阀        │
 └────────────────────────────────────────────────┘

关阀：BLE cmd 14，data = "00" + 8字节ID（不需要服务器）
```

协议细节见 [`docs/协议说明.md`](docs/协议说明.md)。

## 常见问题

**Q：提示「服务器拒绝 / 用户身份失效 (-44)」？**
登录票据过期了。在微信里重新登录一次乐校通，然后重跑 `安装配置.bat`。

**Q：提示「请求已过期，请核对设备时间 (-45)」？**
这是 `X-Ghost` 请求头算错了。本工具会自动按当前时间生成，正常不会出现；
如果你在改代码，注意它**不是随机数**，而是 `校验 + 时间戳HEX + 校验`。

**Q：蓝牙连不上？**
① 电脑蓝牙是否打开 ② 是否在水控器几米内 ③ 手机上的乐校通是否正占用该设备
（微信小程序连着蓝牙时，电脑连不上）。

**Q：为什么不能离线开阀？**
设备只认服务器签发的令牌。令牌由服务器根据设备给出的随机挑战计算，
纯离线伪造在原理上不可行。

**Q：会多扣钱吗？**
不会。这就是正常的用水计费，和你用小程序开一样，走你自己的账户。

**Q：我的宿舍设备型号不一样，能用吗？**
目前只在 **BT19S-T** 上完整验证过。小程序源码里还有 DSK / LRD / GM510 / ESP
等分支（不同的蓝牙特征值），理论上可以适配，欢迎提 issue。

## 致谢 / 技术注解

协议是通过分析乐校通小程序（解密其 wxapkg 包）逆向得到的，关键点：

* **帧格式**：`A5 <len> <d> <g> <c1> <c2> <c3> <data> <sum>`，`len + 3 = 总字节数`
* **校验**：`c = (0xAA + (x ^ g ^ d)) & 0xFF`（**不是 CRC**）
* **转义**：`A5 → 1BE7`，`1BE7 → 1B00E7`
* **X-Sign**：`md5("1FF75E512" + body)`
* **X-Ghost**：`累加校验 + 毫秒时间戳HEX(12位) + 异或校验`（**不是随机数**）
